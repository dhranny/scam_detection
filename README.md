# Scam Detection

This is a mobile app that does a sentiment analysis on text and reports to relevant bodies.

## Bio
This is an AI project to detect spam text. It analyses text messages to detect if they contain the characteristics of fraudulent text messages. It works behind the scenes with a Random Forest ML algorithm.
